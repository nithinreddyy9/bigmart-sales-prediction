# Big Mart Sales Prediction

This project focuses on predicting sales for Big Mart stores using supervised machine learning algorithms.

## Project Overview
The goal of this project is to build predictive models that estimate product sales based on historical sales data, store information, and product-related features.

## Algorithms Used
- Linear Regression
- Decision Tree
- Random Forest
- XGBoost

## Technologies Used
- Python
- Machine Learning
- Data Analysis
- Jupyter Notebook
- Scikit-learn

## Features
- Data preprocessing
- Feature engineering
- Sales prediction
- Model evaluation using RMSE and R² score

## Outcomes
The project helps improve:
- Inventory management
- Business decision-making
- Sales forecasting accuracy
- Customer satisfaction
