# Big Mart Sales Prediction

Machine Learning project for predicting Big Mart store sales using supervised learning algorithms.

---

## Project Overview

The goal of this project is to build a predictive model that estimates product sales based on historical sales data, product details, and store information.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Jupyter Notebook

---

## Algorithms Used

- Linear Regression
- Decision Tree
- Random Forest
- XGBoost

---

## Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Sales Prediction

---

## Dataset Features

- Item Weight
- Item Fat Content
- Item Visibility
- Item Type
- Item MRP
- Outlet Identifier
- Outlet Size
- Outlet Location Type
- Outlet Type

Target Variable:
- Item_Outlet_Sales
